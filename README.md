# Physics Hon (Jr.) Semester 1

Contains graphs for my semester 1 Physics Honors course in the 11th grade of high-school.  
All graphs are made in Hy using Matplotlib. Hy is a Lisp dialect that runs on top of Python. I aim to keep rendering as functional as possible.

## AI/Generative Tools Usage

### Ethics

AI will be used ONLY for brace misplacement and minor syntax or logic corrections.  
Any other AI usage will be explicitly noted and only for collecting sources.  
I will ensure all AI usage complies with the Holy Ghost Preparatory School Student Handbook under the "Use of Artificial Intelligence" section.

#### Permitted AI usage

- Misplacement of/unbalanced braces that cannot be easily fixed manually
- Minor syntax errors that do not affect logic that deal solely with Hy's nuances
- Minor logic errors unrelated to equations that do not affect overall structure or integrity of the code that may arise from code flow
- Collecting sources for further research (via Copilot's `websearch` tool)

#### Prohibited AI usage

- Writing functions or significant portions of code
- Writing comments or documentation
- Any usage not explicitly noted in the code or documentation

### AI will

- Be used to support education and growth
- Be cited where applicable
- Not be used to complete assignments or projects in place of original work

### AI will NOT

- Be used for plagiarism
- Replace original thought

## Materials
